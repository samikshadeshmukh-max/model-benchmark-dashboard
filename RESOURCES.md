# Resources

## 1. What is this project?

Model Benchmark Dashboard is a simple web application for comparing open-weight AI models using benchmark scores.

The goal is to make model comparison easier to understand through a table and visual charts.

This project is intentionally kept simple. It is not a model-hosting platform, training system, or full AI evaluation platform.

## 2. Concepts you need to know

Before contributing, it is useful to understand:

- AI and Large Language Models (LLMs)
- Open-weight AI models
- AI benchmarks
- MMLU
- GSM8K
- HumanEval
- Basic data visualization
- React components
- TypeScript
- Git and GitHub

## 3. Prerequisites

You should have:

- Node.js installed
- npm installed
- Git installed
- Basic JavaScript or TypeScript knowledge
- Basic React knowledge for frontend issues
